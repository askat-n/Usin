# Usin

Заметки на бесконечном холсте и полезные инструменты для Mac — в одном приложении.

- **Заметки** (Mac и iPhone): холст со сферой в центре, заметки, стрелки, темы, вкладки. Синхронизация через Google Drive. Заметки с отметкой «Для ИИ» доступны ИИ-ассистентам через MCP-сервер (`mcp-server/`).
- **Инструменты Mac** (переносятся из Singluse): умная чёлка, голосовой ввод, буфер обмена, плавная мышь, превью в Dock, живые обои, встречи, виджеты.

План и статус — в [PLAN.md](PLAN.md).

## Сборка

Открой `Usin.xcodeproj` в Xcode и нажми ⌘R. Нужны Xcode 27 и macOS 27 / iOS 27.

На Mac приложение работает без песочницы: части функций нужны «Универсальный доступ» и другие системные разрешения.

## Обновления

Usin раз в день проверяет последний релиз в этом репозитории и предлагает установить его (Настройки → Обновления, или меню Usin → «Проверить обновления…»). Обновление ставится, только если оно подписано той же командой разработчика.

Выпустить версию: поднять `MARKETING_VERSION` и запустить

```bash
Scripts/release.sh "Что нового"
```
